# Amazon Inventory Analyst Pro

纯前端亚马逊库存分析工具，可本地运行，也可部署到 GitHub Pages 作为共享网页使用。

## 本地运行

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## 部署到 GitHub Pages

1. 把项目推送到 GitHub 仓库的 `main` 或 `master` 分支。
2. 打开仓库 `Settings` -> `Pages`。
3. 在 `Build and deployment` 里把 `Source` 选择为 `GitHub Actions`。
4. 推送代码后，GitHub Actions 会自动构建并发布 `dist`。
5. 部署完成后，访问 `https://你的用户名.github.io/仓库名/` 即可使用。
